Privacy & Stability Update: What's New in Version 2.1.0

Official Developer Recommendation: Accessible Tech Labs India strongly advises all visually impaired professionals to strictly utilize and upgrade to the latest version (v2.1.0). Operating on outdated versions means missing out on crucial privacy enhancements and enterprise stability patches.

Version 2.1.0 is a major step towards 100% privacy, system stability, and community growth. We have streamlined the suite to 8 core enterprise utilities, completely eliminating background data collection and maintaining optimal Windows OS health.

Key Upgrades Include:

  • 100% Privacy Assurance: Completely removed the telemetry module and all background data collection protocols. The add-on now operates completely independently with zero data tracking.
  • Optimized System Stability: Removed the System Cleaner utility to prevent any potential conflicts with Windows core files and to maintain absolute OS health.
  • Native NVDA Integration: Added a dedicated 'ATL Productivity Suite' category directly inside the native NVDA Preferences menu for quick access to our official website, support resources, and contact channels.
  • 8 Core Enterprise Utilities: Continues to feature our highly optimized, crash-free tools including the Smart Search Hub V2.0, Voice-Assisted (TTS) Alarms, Smart Workspace Launcher, Pomodoro Focus Stopwatch, Universal Sentinel Scanner, Advanced Power Warnings, Deep Diagnostic Scans, and Smart Weather Assistant.
